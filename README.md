# 👗 Sri Sainath Her Choice

`Static Site` `HTML/CSS/JS` `Fashion Retail` `Admin Panel`

> Premium women's & kids' clothing in Kamalanagar, Anantapur.

## What is this?

A landing page for Sri Sainath Her Choice, a women's and kids' clothing
store — premium women's clothing, kids' collection, and daily wear —
plus a lightweight admin page for managing site content.

## ✨ Highlights

- 👚 Product and collection showcase
- 🔐 Simple admin panel for content updates
- 🖼️ Store and product photo gallery

## 🛠️ Tech Stack

Static **HTML**, **CSS**, and vanilla **JavaScript** — no build step, no
framework. `patch.py` is a standalone Python utility (not part of the
served site) for offline image/content updates.

## 📁 Structure

```
index.html                 # public landing page
admin.html / admin.css / admin.js   # admin content management
index.css, index.js          # public page styles/behavior
```

## 🚀 Running Locally

```bash
python -m http.server 8000
```
